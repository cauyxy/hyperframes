The real product loop

The docs should teach this human loop first. Package architecture appears only when a developer needs it.

1 · IntentRequest, URL, PR, footage, music, or design
2 · AgentSkills choose a workflow and create direction
3 · ProjectEditable HTML, media, timing, and assets
4 · ControlAgent, Studio, CLI, or source code
5 · VerifyPreview, lint, check, and review
6 · DeliverVideo, deck, embed, render, or reusable source

What is broken now

Not “too many words” or “too few words” by itself. The system often gives different kinds of information the same shape.

Router chainsSeveral pages only introduce another set of links, so a reader clicks two or three times before reaching the answer.
Micro-pages without a resultSome Studio pages describe a panel in roughly one screen but do not show a real task, expected result, or recovery.
Mixed content modesTutorials, how-tos, concepts, and references are written and judged as if they were the same thing.
Uncontrolled mediaPortrait clips, complete films, and tiny UI loops share similar dimensions and playback behavior.
Duplicate teachingWorkflows and Prompt Guide sometimes explain the same creation path instead of having separate jobs.
Repository-shaped depthDeveloper pages expose package boundaries before helping someone choose the smallest useful technical surface.

Every page declares its type

A page is judged by whether it completes its own job, not by a universal word count.

Journey

Orient end to end

Film, concise written path, one dominant next action. Only four routes.

Tutorial

Learn through a project

One real example, visible checkpoints, finished outcome, recovery.

How-to

Complete one task

Minimum steps, expected result, compact proof, common pain point.

Explanation

Understand a model

One clear claim, diagram or example, why the distinction matters.

Reference

Look up exact facts

Scannable and complete. Length is allowed; narrative video is not.

Router

Choose deliberately

Only at major entrances. Teaches the difference; never just a card wall.

Troubleshooting

Return to the task

Symptom → cause → smallest fix → verification → escalation.

Catalog item

Judge and reuse

Truthful preview, best use, install contract, options, source.

Media grammar

A video is useful only when it communicates motion, interaction, workflow, or a complex visual idea faster than text.

Journey film · 16:9

Complete film

Full content width. Controls. No autoplay or loop. Narration, BGM, SFX, captions, and transcript.

UI proof loop

Compact demonstration

One or two columns. Autoplay muted loop. No controls. Usually 8–20 seconds.

Portrait

Constrained format

Centered and height-capped. It never consumes multiple viewports merely because its source is vertical.

Implementation, after approval

No more “all done” because routes open. Each phase ends with a concrete browser preview and quality report.

Principles used

Grounded in Diátaxis, Mintlify navigation guidance, GitHub's content model, Google procedure guidance, and Cloudflare's video criteria. The resulting system is adapted to HyperFrames rather than copied from any one framework.
