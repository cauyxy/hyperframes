What a page must earn

Every route is judged by the reader’s job, not by its word count.

Journey Orient, prove the result, explain the mental model, and offer one dominant next action.
Task guide Let a reader finish one real job without an unnecessary intermediate click.
Concept Explain a model or boundary that makes later decisions easier.
Reference Make exact commands, contracts, options, and behavior easy to find and verify.
Router Exist only when choosing is itself the reader’s task; never repeat the sidebar as cards.

Visual rule

  • A complete outcome or journey earns a narrated film with controls.
  • One visible interaction earns a compact muted loop from the current product.
  • A transformation earns a same-source before/after, not two unrelated examples.
  • A stable UI location earns one current screenshot.
  • Commands and schemas earn copyable verified code, not decorative video.
  • Troubleshooting earns exact symptoms and output. Many pages correctly need no visual.

What external teaching changes

  • Lead with the viewer’s job and a real result before setup or renderer architecture.
  • Follow one artifact from request through a correction to the finished file.
  • Promise a playable first version, not one-shot perfection.
  • Teach brand and motion direction before piling on more feature vocabulary.
  • Distinguish local HyperFrames from hosted HeyGen by the artifact and control the user receives; Video Agent can now use HyperFrames motion graphics internally.
  • Do not copy third-party “zero setup,” “pixel-perfect every time,” or stale CLI claims.
